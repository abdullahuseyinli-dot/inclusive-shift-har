# Changelog

This file summarizes user-visible software and evidence changes. Immutable
experiment tags, failed release candidates, and exact hashes remain documented in
their original records and Git history.

## Unreleased

### Added

- A structured research report and experiment map separating locked target,
  source-development, personalization, and external diagnostic results.
- A current evidence index, supersession map, documentation map, CTGR/HERA model
  card, reproducibility guide, and finite GitHub/Zenodo publication checklist.
- Audited AICOS-HAR adapter and source-frozen external benchmark controls.
- A create-only native-nine CTGR confirmation workflow with label-blind prediction
  sealing, participant-level scoring, and explicit SI-to-g conversion.
- A fixed source/AICOS routing-validation controller and focused contract tests.
- Contribution and sensitive-data reporting guidance.

### Changed

- Integrated the reviewed research history into `main`, presented the strongest
  results by evaluation protocol, and pinned the existing benchmark tag so main
  can advance without changing historical evidence.
- Corrected the canonical table's single-seed/five-seed grouping and clarified
  the selected denoised GSP feature path and limits of HARTH placement evidence.
- Removed a private sibling-checkout dependency from the FoG configuration
  test while retaining production hash checks and testing rejection of tampering.
- Enabled Git long-path support in Windows CI and documented the matching clone
  option for preserved evidence filenames.
- Validated citation metadata against the CFF 1.2 schema and recorded an exact
  historical probability-identifier false positive in the secret-scan policy.
- Reframed the README and project status around the final research disposition.
- Corrected the AICOS acceleration/gravity interface for g-trained source models.
- Closed unconditional U9 posture routing after source regression and no practical
  gain on the larger AICOS development cohort.
- Excluded preserved temporary HARTH reference inputs from the publication index
  while retaining their local audit hashes.

### Evidence status

- CTGR remains the strongest justified source-development advancement.
- Strict HERA-v1 remains the highest matched source point estimate without an
  independently supported gain over CTGR.
- The historical locked target outcome and negative MoRe-HAR hypothesis decision
  are unchanged.
- No new target opening, independent confirmation, GitHub release, or Zenodo DOI
  is claimed.
