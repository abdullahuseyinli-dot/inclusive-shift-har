manifest copied all inclusive-native window counts from the parent split while the
runner requested the functional-core ontology. For target participant 13, the manifest
declared 160 windows and the functional-core filter correctly found 78.

No adaptation, target prediction, or target performance was computed. The empty
create-only scenario directory is preserved locally. The committed v1 manifest is not
rewritten; a corrected functional-core-bound revision must supersede it.
