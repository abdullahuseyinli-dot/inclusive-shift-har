# Dataset-derived artifact terms and attribution

These predictions, labels, pseudonymous identifiers and associated evaluation
records derive from FoG-STAR v3 by Luigi Borzi and co-authors. Cite the pinned
[dataset record](https://doi.org/10.5281/zenodo.17838806) and its
[Scientific Data descriptor](https://doi.org/10.1038/s41597-026-06645-1).
The full creator list is retained by the pinned provider record.

The dataset and this dataset-derived evidence are provided under
[Creative Commons Attribution 4.0](https://creativecommons.org/licenses/by/4.0/).
The repository's Apache-2.0 code license does not relicense these artifacts.
Changes relative to provider data: repository-defined signal preprocessing,
post hoc window/ontology admission, participant-exclusive model fitting and
derived predictions/metrics. These are not the original raw sensor recordings.
No provider or participant endorsement is implied. No clinical, confirmation,
SOTA or publication-acceptance claim is made.

Raw source files and model checkpoints remain outside Git. Checkpoint paths in
the preserved result records describe retained local evidence, not included
downloadable weights. All candidate outcomes, including the failed PB-HPF gate,
are retained. This is an intermediate completed-evidence checkpoint; the other
dataset campaigns and final manuscript freeze remain separate work.
